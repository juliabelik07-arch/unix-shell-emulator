# Эмулятор оболочки UNIX (Вариант №3)

## Этап 1. REPL (Read-Eval-Print Loop)

Реализован минимальный прототип командной оболочки.

**Выполненные требования:**
1. Консольный интерфейс (CLI) — цикл `while True`.
2. Приглашение формируется на основе реальных данных ОС: `user@host:path$`.
3. Реализован парсер с раскрытием переменных окружения (например, `$HOME`).
4. Реализованы команды-заглушки `ls` и `cd`.
5. Реализована команда `exit`.
6. Обработка ошибок: неверный путь в `cd`, неизвестная команда.

## Этап 2. Конфигурация

Реализована настройка эмулятора через параметры командной строки и поддержка скриптов.

**Выполненные требования:**
1. Параметры командной строки: `--vfs` и `--script`.
2. Отладочный вывод всех заданных параметров при запуске.
3. Стартовый скрипт поддерживает комментарии (строки с `#`).
4. При выполнении скрипта отображается как ввод, так и вывод (имитация диалога).
